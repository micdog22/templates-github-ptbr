# Suporte

Precisa de ajuda com o {{NOME_DO_PROJETO}}? Veja abaixo o melhor caminho para cada situação.

## Antes de perguntar

- Leia o README e a documentação do projeto.
- Procure nas issues, inclusive nas fechadas, e nas discussões: outra pessoa pode já ter tido a mesma dúvida.

## Onde pedir ajuda

| Situação | Onde |
| --- | --- |
| Dúvida sobre como usar | Nas [Discussões]({{URL_DO_REPOSITORIO}}/discussions), se estiverem ativadas, ou em uma issue com o formulário "Dúvida" |
| Encontrou um bug | Issue com o formulário "Relatar bug" |
| Ideia ou recurso novo | Issue com o formulário "Sugerir melhoria" |
| Falha de segurança | Nunca em público: siga a [política de segurança](SECURITY.md) |
| Problema de conduta | E-mail para {{EMAIL_DE_CONTATO}} (veja o [Código de Conduta](CODE_OF_CONDUCT.md)) |

## Como fazer uma boa pergunta

- Conte o que você está tentando fazer, não só o erro que apareceu.
- Informe a versão do projeto, o sistema operacional e como fez a instalação.
- Mostre o que já tentou e qual foi o resultado.
- Cole mensagens de erro como texto, dentro de um bloco de código, em vez de capturas de tela.
- Se puder, monte um exemplo mínimo que reproduza o problema.

## O que esperar

Este é um projeto de código aberto, mantido em grande parte no tempo livre de quem colabora. Respondemos assim que possível, mas não há prazo garantido nem atendimento individual por mensagem privada. Perguntas feitas em público também ajudam quem tiver a mesma dúvida no futuro.
